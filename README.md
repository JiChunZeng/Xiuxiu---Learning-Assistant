# 秀秀编程带学

长沙师范学院，大一，大数据管理与应用。每天 30–60 分钟做一件日常小工具。任务、代码和学习记录都在这一个私有仓库里。她说「开始」就会拉到最新任务；她做完会上传；你说「同步」就能看到进度。

## 现在

架子先搭好，第一天先不开始。`她做的/可以上课.txt` 里写着「先不开始」。她即使输入「开始」，也只会被告诉今天不学习。

要上课时，把这个文件改成「可以」，推送后再让她输入「开始」。

## 她每天

用 Cursor 打开桌面上的「我的一天」，对话里输入 `开始`。不用从微信发提示词。

## 你这边

在这个仓库里说「同步」。助手会先拉取，再按她上传的学习记录更新 `跟踪/进度表.md` 并写日报。

| 你说 | 时候 |
| --- | --- |
| 同步 / 出日报 | 她上传之后 |
| 出周报 | 每一周的第 7 天有了记录 |
| 出月报 | 第 4、8、12 周的周报之后 |
| 出学期总结 | 第 12 周演示之后 |

你改了大纲或提示词，助手会推上去。她下次说「开始」会先拉到。

## 谁改哪些文件

- 她只写 `她做的/`：代码、需求、笔记、学习记录、下一课。
- 你只写进度表、大纲、提示词。
- 两边都先拉取再改。冲突时先停，不要覆盖 `她做的/`。

## 她电脑上的一次设置

仓库地址：https://github.com/JiChunZeng/Xiuxiu---Learning-Assistant

在她的电脑上做一次：

1. 安装 Git。
2. 只给这个私有仓库做一个细粒度令牌：GitHub → Settings → Developer settings → Fine-grained tokens → 只选这个仓库 → Contents 设为 Read and write。令牌只在她电脑的终端里贴一次，不要发进聊天记录。
3. 克隆后在仓库里设置提交署名，让记录上能看出是她交的：

```
git clone https://github.com/JiChunZeng/Xiuxiu---Learning-Assistant.git
cd xiuxiu
git config user.name "秀秀"
git config user.email "xiuxiu@users.noreply.github.com"
```

克隆问密码时，用户名填 GitHub 用户名，密码填刚才的令牌。

4. 用 Cursor 打开这个文件夹。对她说：以后每天打开，输入「开始」。

日期表从 2026-10-22 起算。晚开始就改 `跟踪/进度表.md` 的日期列，不要跳课次。`她做的/下一课.txt` 现在是 `1周1天`。

## 进度怎么停

下面任何一条成立，下一天都留在原任务：

- 她没做完，或记录里写卡住了
- 陪练把完整答案直接给了她
- 情绪是「烦」或「想停」
- 当天超过 70 分钟

第 7 天写成休息，也算这一天落实了。

## 文件

- `她做的/学习记录/`：她上传的原始记录
- `大纲.md`：十二周，每周一件程序员的事
- `给她/程序员做法.md`：需求、设计、找资料
- `给她/每日提示词.md`：第一月 28 天
- `给你/报告提示词.md`：日报到学期总结
- `跟踪/进度表.md`：落实表
- `.cursor/rules/`：她说「开始」走陪练，你说「同步」走进度
